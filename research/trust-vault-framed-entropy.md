# Trust Vault: framed-entropy thesis

Developed in conversation 2026-08-18. This is the operational form of the whole
thesis — the one quantity the earlier concepts reduce to.

## The claim (CLAIM-006)

> A node's value to the network equals the entropy difference it creates:
> H(unframed) − H(framed), measured in bits/time over the same underlying referent.
> Nodes that reduce entropy for the network survive and compound; nodes that
> increase or merely rearrange entropy are outcompeted. Framed entropy is cheaper
> for the network to evaluate than unframed entropy of the same thing.

## Definitions

- **Entropy** = undifferentiated bits/time; raw chaotic energy without a frame,
  expensive for a network to evaluate. "Everything is entropy without a frame."
- **Framed entropy** = the bits/time a network must spend to evaluate a thing after
  a node has structured it.
- **Node value** = H(unframed) − H(framed), over the **same referent**. The frame
  reduces the network's evaluation cost for the same underlying thing; it is not a
  comparison of two unrelated entropy streams.
- **Energy = bits/time.** Things only show up online if there is energy behind them
  to record the observation. Bits/time is a survivorship-consistent measure of
  observable energy. Inefficient computation is killed by selection, which is what
  makes the bits/energy proxy converge over time.

## How it collapses the thesis

- **HumanPower Index** = entropy reduced for humans. Human time saved *is* bits of
  evaluation the human no longer spends. The index is the measurement instrument.
- **Trust vault** = the framing mechanism. Captures chaotic energy, discharges as
  framed entropy; its value is the entropy difference it produces.
- **Shorting complexity** = betting that nodes which fail to frame entropy get
  killed; nodes that frame it survive. Selection enforces "inefficient computation
  dies."
- **Verification fog** = unframed entropy is expensive to evaluate; framed is cheap.
  The market pays the fog cost; the framing practitioner doesn't.
- **PvE** = the reference frame is unframed entropy itself. Competition is the chaos
  being simplified, not a rival node.
- **Overlapping systems** = energy retained across the network, not one node.

## Falsifiers

1. A node that removes bits is not retained by the network (value without survival).
2. A node is retained while increasing network entropy (survival without value).
3. The framed version of a thing costs *more* bits to evaluate than the unframed
   version (compression ratio inverted).

## Open questions before measurement

- Which substrate does the vault measure first (on-chain data, social feed,
  transaction volume)? The unit is bits/time but the substrate must be countable.
- Is the "market alternative" reference the external compensation market, the
  internal network's own return, or the entropy baseline itself? This picks the
  ground for the retention condition.
